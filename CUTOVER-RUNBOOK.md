# CUTOVER RUNBOOK

Use this template for any deploy that changes the interpretation of persistent or operational state.

## Rule
Stages are mandatory and must run in this exact order:

1. snapshot
2. audit
3. clean
4. deploy
5. smoke

Do not skip `clean` when the release changes how existing persisted state is interpreted.
