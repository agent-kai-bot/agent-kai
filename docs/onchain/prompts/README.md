# Onchain Prompt Starters

Use this folder for prompts that combine onchain signals with technical context.

## Starter template

```text
Do not just summarize the data. Build a reusable onchain-analysis workflow for {SYMBOL} or ecosystem.

Requirements:
- define the signal inputs
- define confirmation and rejection rules
- explain when the setup matters
- end with a reusable playbook section:
  - when to use
  - inputs required
  - steps
  - pitfalls
  - verification
```
